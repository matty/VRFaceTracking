# Cymple Module

Native Rust tracking module for VRFaceTracking, receiving eye tracking data from [Project Cymple](https://github.com/Dominocs/Project_Cymple) via binary UDP on port 22999.

## Original Project

This module is a native Rust reimplementation of [CympleFaceTracking](https://github.com/Dominocs/CympleFaceTracking) by **Dominocs**, originally written in C# for VRCFaceTracking.

Thank you to Dominocs for the original Cymple tracking module.
