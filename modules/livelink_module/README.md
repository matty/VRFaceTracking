# LiveLink Module

Native Rust tracking module for VRFaceTracking, receiving face tracking data from the Unreal Engine [Live Link Face](https://apps.apple.com/app/live-link-face/id1495370836) iOS app via binary UDP on port 11111.

## Original Project

This module is a native Rust reimplementation of [VRCFaceTracking-LiveLink](https://github.com/Dazbme/VRCFaceTracking-LiveLink) by **Dazbme**, originally written in C# for VRCFaceTracking. The module was later updated for VRCFaceTracking v5 by [kusomaigo](https://github.com/kusomaigo/VRCFaceTracking-LiveLink).

Thank you to Dazbme for the original LiveLink module and to kusomaigo for the v5 update.
