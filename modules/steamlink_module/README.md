# SteamLink Module

Native Rust tracking module for VRFaceTracking, receiving face tracking data from SteamLink via OSC on port 9015.

## Original Project

This module is a native Rust reimplementation of [LinkFT](https://github.com/ykeara/LinkFT) by **ykeara**, originally written in C# for VRCFaceTracking.

Thank you to ykeara for the original SteamLink integration.
