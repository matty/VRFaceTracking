# iFacialMocap Module

Native Rust tracking module for VRFaceTracking, receiving face tracking data from the [iFacialMocap](https://www.ifacialmocap.com/) iOS app via pipe-delimited text over UDP on port 49983.

## Original Project

This module is a native Rust reimplementation of [VRC_iFacialMocap](https://github.com/Shuisho10/VRC_iFacialMocap) by **Shuisho10**, originally written in C# for VRCFaceTracking.

Thank you to Shuisho10 for the original iFacialMocap module.
