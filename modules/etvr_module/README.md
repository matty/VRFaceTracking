# EyeTrackVR (ETVR) Module

Native Rust tracking module for VRFaceTracking, receiving eye tracking data from [EyeTrackVR](https://github.com/EyeTrackVR) via OSC on port 8889. Supports both V1 and V2 OSC protocols with automatic detection.

## Original Project

This module is a native Rust reimplementation of [ETVRTrackingModule](https://github.com/EyeTrackVR/ETVRTrackingModule) by the **EyeTrackVR** team, originally written in C# for VRCFaceTracking.

Thank you to the EyeTrackVR team for the original tracking module.
