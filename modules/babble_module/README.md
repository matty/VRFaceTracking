# Babble Module

Native Rust tracking module for VRFaceTracking, receiving mouth tracking data from [Project Babble](https://github.com/Project-Babble/ProjectBabble) via OSC on port 8888.

## Original Project

This module is a native Rust reimplementation of [VRCFT-Babble](https://github.com/dfgHiatus/VRCFT-Babble) by **dfgHiatus**, originally written in C# for VRCFaceTracking.

Thank you to dfgHiatus for the original Project Babble module.
