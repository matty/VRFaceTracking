# MeowFace Module

Native Rust tracking module for VRFaceTracking, receiving face tracking data from the [MeowFace](https://play.google.com/store/apps/details?id=com.suvidriel.meowface) Android app via JSON over UDP on port 12345.

## Original Project

This module is a native Rust reimplementation of [VRCFaceTracking-MeowFace](https://github.com/regzo2/VRCFaceTracking-MeowFace) by **regzo2**, originally written in C# for VRCFaceTracking.

Thank you to regzo2 for the original MeowFace module.
